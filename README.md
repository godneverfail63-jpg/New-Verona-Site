# VERANO Portfolio (free, GitHub Pages only)

No Netlify, no backend, no credits. Four files do everything:

| File | What it does |
|---|---|
| `projects.js` | **Your content.** Email, social links, and every project. |
| `index.html` | Page structure and your service text. |
| `style.css` | Colors and layout (black and gold). |
| `app.js` | Makes the project pages work. You never need to touch this. |

## Put it live (about 5 minutes)
1. github.com → **New repository** → name it `verano` (or `yourusername.github.io`) → **Public** → Create.
2. Click **uploading an existing file**, drag in ALL files from this folder (including the `assets` folder and `.nojekyll`), then **Commit changes**.
3. **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save.**
4. Wait about 1 minute. Your link appears at the top of that Pages screen.

## Add a project
1. Upload photos to the `assets` folder on GitHub (Add file → Upload files). Keep each under 25 MB; compress big photos first.
2. Open `projects.js` → pencil icon → copy one project block, paste it, change the text.
3. Hero image: `heroImage: "assets/my-photo.jpg"`. Video: paste a YouTube (unlisted) or Vimeo link into `videoUrl`.
4. Commit. The site updates in about a minute.

## Tips
- Don't upload big videos to GitHub. Use YouTube unlisted and paste the link.
- File names are case-sensitive: `Photo.JPG` is not `photo.jpg`. Use lowercase with dashes.
- Custom domain later (about $10 to $15 per year): Settings → Pages → Custom domain.
